## 🎓 GETTING STARTED

### Step 1: Install Extension
See "INSTALLATION (5 MINUTES)" above

### Step 2: Get API Key
Choose one (all have free tiers or trial):
- **Google Gemini**: https://aistudio.google.com/app/apikey
- **OpenAI**: https://platform.openai.com/api-keys
- **Anthropic Claude**: https://console.anthropic.com/

### Step 3: Configure
1. Click extension icon (✨)
2. Paste API key
3. Choose provider & style
4. Click "Save"

### Step 4: Use It!
1. Go to Gmail, Twitter, Google Docs, etc.
2. Click text field
3. Type text
4. Click ✨ icon
5. Enjoy refined text!
