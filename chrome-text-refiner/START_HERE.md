## 🏃 Quick Installation (5 Minutes)

### Step 1: Open Chrome Extensions
1. Open Google Chrome
2. Type this in the address bar: `chrome://extensions/`
3. Press Enter

### Step 2: Enable Developer Mode
- Look for the toggle in the **top-right corner** labeled "Developer mode"
- Click it to **turn it ON**

### Step 3: Load Unpacked Extension
1. Click the blue button **"Load unpacked"**
2. Navigate to: `/Users/ronakkumar/Desktop/refine/chrome-text-refiner`
3. Click **"Select Folder"**
4. ✨ The extension is now installed!

### Step 4: Get an API Key (Choose One)

**Option 1: Google Gemini (RECOMMENDED - Has free tier)**
- Go to: https://aistudio.google.com/app/apikey
- Click "Create API Key"
- Copy the key

**Option 2: OpenAI (ChatGPT)**
- Go to: https://platform.openai.com/api-keys
- Create new secret key
- Copy the key

**Option 3: Anthropic (Claude)**
- Go to: https://console.anthropic.com/
- Navigate to API Keys
- Create and copy key

### Step 5: Configure the Extension
1. Look for the ✨ icon in your Chrome toolbar (might be in the extension menu)
2. Click it to open settings
3. Paste your API key in the "API Key" field
4. Click **"Save Settings"**
5. ✅ Done!

## ⚙️ Settings Explained

When you click the extension icon, you see these options:

- **Provider**: Choose your AI (Gemini, OpenAI, Claude, Custom)
- **API Key**: Your authentication (kept secure!)
- **Model**: Which AI model to use
- **Temperature**: 0 = precise, 1 = creative (use 0.7 for default)
- **Refinement Style**: How to improve text (Professional, Casual, etc.)

## 🆘 Troubleshooting

### Icon not appearing?
- Refresh the website (F5)
- Click a text field and start typing

### "Invalid API Key" error?
- Check the API key is copied correctly (no extra spaces)
- Make sure you're using the right provider's key

### Settings not saving?
- Check if you're signed into your Google/Chrome account
- Try refreshing the page
