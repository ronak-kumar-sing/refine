# Roadmap

This document outlines the vision and planned features for AI Text Refiner.

## 📋 Current Status

**Current version**: 1.1.0  
**Last updated**: November 14, 2026

## 🎯 Vision

AI Text Refiner aims to be the most user-friendly, privacy-first AI text refinement tool for the web, supporting multiple AI providers with beautiful UX and zero data collection.

## 🚀 Planned Features

### Version 1.1 (Q1 2026)

- [ ] **Batch Processing**: Refine multiple text fields at once
- [ ] **Custom Presets**: Save frequently used refinement configurations
- [ ] **Redo Support**: Redo changes after undo
- [ ] **Text History**: View refinement history for each field
- [ ] **Performance Improvements**: Faster processing and reduced memory usage

### Version 1.2 (Q2 2026)

- [ ] **Language Detection**: Auto-detect and preserve language
- [ ] **Tone Analysis**: Show detected tone before refinement
- [ ] **Custom Refinement Patterns**: Create refinement workflows
- [ ] **Browser Sync**: Sync settings across devices (optional)
- [ ] **Better Error Messages**: More helpful error descriptions

### Version 1.3 (Q3 2026)

- [ ] **Firefox Support**: Extend to Firefox and other browsers
- [ ] **Context Menu**: Refine text directly from context menu
- [ ] **PDF Support**: Refine text in PDFs
- [ ] **Grammar Check**: Pre-check grammar before refinement
- [ ] **Style Transfer**: Match writing style of provided text

### Version 2.0 (Q4 2026 - Major Release)

- [ ] **Collaborative Editing**: Share refinement suggestions
- [ ] **Team Features**: Organization-wide settings
- [ ] **Advanced Analytics**: Usage statistics and insights
- [ ] **Mobile Support**: Companion mobile app
- [ ] **AI Model Comparison**: Compare outputs from multiple models
- [ ] **Offline Mode**: Support for local LLMs with better integration

## 🔬 In Research

- Language-specific refinement
- Real-time spell checking
- Writing style analysis
- Integration with popular platforms (Gmail, Google Docs, etc.)
- Voice-to-text refinement
- Video caption refinement

## 🐛 Known Limitations

- Only works in Chromium-based browsers (Chrome, Edge, Brave, etc.)
- Requires active internet connection (except with local LLMs)
- Character limit depends on selected API provider
- Cannot refine text in some custom text editors

## 🔄 Development Priorities

1. **Stability**: Bug fixes and performance
2. **Usability**: Better UX and documentation
3. **Features**: New capabilities based on feedback
4. **Community**: Support for contributors
